# Who works on Jarrow

Generated by tools/contributors.py. Do not edit by hand.

The people, agents, and bots and automation that work on this repository, and what each one does. The same list is in the [README](../README.md#who-works-on-jarrow) and on the site's [Contributors](https://jarrow.pages.dev/contributors/) and [About](https://jarrow.pages.dev/about/) pages.

Commit counts come from `git log` on `main`, up to the newest counted commit (2026-11-03T18:39:42Z), and every member shows one, 0 included. A commit counts for every agent its trailers name. A bot's count is the commits it authored: a squash merge is authored by the pull request's author, so each merged pull request from Dependabot, Renovate or a bot branch (github-actions[bot]) counts once. The refresh commit that updates this list counts once another commit lands on top of it, so a refresh never causes another one.
