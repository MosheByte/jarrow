Without it the harness will not start a server and no mod can be green. The Cloudflare CI token was attempted through the wrangler OAuth REST API, the Cloudflare API connector and Composio, and all three refused (exact errors in `infra/TODO-OWNER.md`), so the site deploys from this machine until a token exists. Later-milestone items (OAuth app, registry tokens, Discord, Sponsors, org transfer) will be attempted when their milestone starts.
