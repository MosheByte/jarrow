# Start here

1. Open this folder in Claude Code (Windows, where `gh` is authenticated).
2. Open BUILD-BOOK.md, Appendix 14, copy the whole prompt in the code block.
3. Paste it as the first message. Nothing to replace: the agent creates the GitHub organisation and repository itself.

Do not add instructions between sessions; put them in the book.
To resume after a session ends, use the "How to resume" line at the end of the book.
