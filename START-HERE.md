# Start here

1. Open this folder in Claude Code.
2. Open BUILD-BOOK.md, Appendix 14, and copy the prompt in the code block.
3. Replace <ORG> with the GitHub organisation you created (jarrow, or jarrow-dev if taken).
4. Paste it as the first message. Do not add instructions between sessions; put them in the book.

To resume after a session ends, use the "How to resume" line at the end of the book.
